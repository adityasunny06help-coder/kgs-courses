# 📚 KGS Courses — All Batch Viewers

A beautiful, searchable web viewer for **410+ KGS educational course batches** — covering UPSC, BPSC, NEET, JEE, SSC, Banking, Defence, and more.

🌐 **Live Site:** [https://adityasunny06help-coder.github.io/kgs-courses/](https://adityasunny06help-coder.github.io/kgs-courses/)

---

## ✨ Features

- 🔍 **Search** across all 410+ batches instantly
- 📖 **Subject-wise** video organization inside each batch
- ▶️ **YouTube video player** embedded directly in browser
- 📄 **PDF Notes** download links for each lecture
- 📱 **Fully responsive** — works on mobile, tablet & desktop
- 🌙 **Dark mode** design — easy on the eyes

## 🚀 How to Use

1. Visit the **[live site](https://adityasunny06help-coder.github.io/kgs-courses/)**
2. **Search** for your batch by name
3. Click any batch card to open its viewer
4. Select a **subject** from the left sidebar
5. Click any **video thumbnail** to watch
6. Use the **"View Notes"** button to open PDF notes

- **HTML5** + **Vanilla CSS** + **Vanilla JavaScript**

## 📁 Project Structure

```
kgs-courses/
├── index.html              ← Main homepage with all batch listings
├── _template/              ← Shared viewer template (HTML/CSS/JS)
│   ├── index.html
│   ├── style.css
│   └── script.js
├── build-all.js            ← Script to generate all viewers
├── gen-index.js            ← Script to regenerate homepage
└── [Batch Name]/
    └── viewer/
        ├── index.html      ← Batch-specific viewer
        ├── data.js         ← Video data for this batch
        ├── style.css
        └── script.js
```
